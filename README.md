# Scoutino - سكاوتينو ⚽
من الحارة للنجومية: تطبيق Flutter بيخلي اللاعب الصغير يسجل فيديوهات مهارات، ياخد تقييم، والكشافين يدوروا عليه.

## الميزات
- **بروفايلي:** بيانات اللاعب قابلة للتعديل وبتتحفظ على الجهاز.
- **رفع فيديو:** 4 تسجيلات × 15 ثانية بالكاميرا، وتقدر تعيد أي واحد.
- **نتيجتي:** رادار تشارت وتقييم لكل مهارة (تقييم تجريبي حالياً).
- **بحث الكشاف:** بحث بالاسم/المدينة، فلتر بالمركز، ومفضلة.

## التشغيل على جهازك
```bash
flutter create . --platforms=android
flutter pub get
flutter run
```

## بناء APK بدون ما تثبت حاجة
1. ارفع الفولدر ده على GitHub (Repository جديد).
2. روح تبويب **Actions** > **Build APK** > **Run workflow**.
3. بعد ما يخلص، نزّل `scoutino-apk` من الـ Artifacts.

## للنشر على Google Play
```bash
flutter build appbundle --release
```
لازم قبلها: اسم حزمة فريد، أيقونة، مفتاح توقيع (keystore)، وسياسة خصوصية.
التطبيق بيتعامل مع فيديوهات أطفال، فراجع سياسة Families في Google Play وخد موافقة ولي الأمر.

## ملاحظات
- التقييم حالياً أرقام تجريبية مشتقة من الفيديوهات (الدالة `_computeScores` في `lib/app_state.dart`) وهتتبدل بتحليل حقيقي.
- الفيديوهات والبيانات محلية بس. `supabase_schema.sql` جاهز لما نربط الباك إند.
